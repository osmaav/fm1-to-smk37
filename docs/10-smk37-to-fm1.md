# 10: SMK-37 на FM-1 (обратный перенос)

Остальная часть этого комплекта переносит прошивку FM-1 на SMK-37. Эта страница идёт в обратную сторону:
прошивка, сначала написанная для SMK-37 (или выросшая там, как Vox37), получает цель FM-1. FM-1 — меньшая
панель: меньше клавиш, меньше органов управления, нет пэдов, фейдеров и колёс. Чип, аудиотракт, USB и протокол
обновления те же, поэтому основная работа — панель и карта флеша. Читайте [01-hardware.md](01-hardware.md) для
сравнения двух плат; эта страница перечисляет, что меняется в обратном направлении и в каком порядке.

## 1. Две панели

| Элемент | SMK-37 | FM-1 | Что делает сборка FM-1 |
|---|---|---|---|
| Клавиши | 37, с velocity (два контакта, заводские кривые в USRTRIM) | 27 (F3..G5), без velocity | Клавиши 5..31 клавиатуры SMK — это клавиши 0..26 FM-1. Используйте фиксированное velocity (100). 10 крайних клавиш не существует |
| Кнопки | 18 (идентификаторы 0..17 в `smk_input.h`) | 14 (идентификаторы матрицы 0..13: OCT- 0, OCT+ 1, FX 2, SEL 3, ENV 4, LFO 5, EDIT 6, GLO 7, HOME 8, SAVE 9, ARP 10, SEQ 11, PLAY 12, REC 13; PANEL_DEFAULT в `panel.c` Felucca) | Сопоставляйте по функции, а не по идентификатору. KNOB BANK, FADER BANK, <, >, PATCH, CHORD, NOTE REPEAT, PARA, BT, SCALE не имеют кнопки на FM-1 |
| Энкодеры | 8 (K1..K8), K1 — виртуальный потенциометр MASTER | 7: SELECT 0, ALGORITHM 1, KNOB 1..4 2..5, PRESETS 6 | MASTER на FM-1 — настоящий потенциометр (ADC, абсолютный 0..1023: сглаживайте и держите мёртвую зону против последних битов). SELECT, ALGORITHM и PRESETS берут то, что на SMK делали пэды и стрелки |
| Светодиоды | 19 светодиодов кнопок (две группы), 16 RGB-пэдов (WS2812 на SPI1) | 14 светодиодов кнопок и 27 светодиодов клавиш в битмапах колонок (`fm1_led[col]`, `fm1_led_key(id)`: кнопки 0..13, клавиши 14..40), тусклое свечение | Цвета пэдов становятся светодиодами кнопок и экраном. Светодиоды клавиш могут показывать ноты, шаги или выбор |
| Пэды, фейдеры, колёса, педаль | есть | нет | Их задачи переезжают на страницы ручек, кнопки или экран (раздел 3) либо уходят |
| Матрица | 4 x 595 через SPI2 DMA, строки PA2, PA5..PA7, PA9, PH6, PH8, PH9 | 2 x 595 бит-бэнгом, строки PA0, PA5..PA8, PB7 | Используйте `fm1_input.h` как есть: его тик, дребезг и декодер энкодеров — от FM-1 |
| Фреймы | 625 в секунду | 909 в секунду | Считайте время в миллисекундах, никогда во фреймах |
| Дисплей | ST7789 240 x 240, SPI1 группа A, без пина подсветки | ST7789 240 x 240 (смещение строки в его инициализации), SPI1 группа B, CS PC7, D/C PC8, подсветка PA2 | `lcd.c` хранит обе таблицы инициализации по платам. Сохраняйте тактовый генератор ЖК FM-1, пока не измерено на устройстве |
| АЦП | тайминг `0x400D` (~40 мкс) | тайминг `0xF04E` / `0xF06E`, MASTER и батарея | На FM-1 используйте `fm1_adc.h`; тайминг SMK остаётся только для SMK |
| MIDI | только USB (PH8 — строка матрицы) | USB и TRS MIDI IN на UART1 / PH8 | TRS MIDI IN может вернуться в сборке FM-1 (`FELUCCA_UART`) |
| Микросхема флеша | JEDEC 0xEB6014 | JEDEC 0x856014 | `FL_JEDEC_OK` по платам |

## 2. Карта флеша, идентичность, пакеты

| Элемент | SMK-37 | FM-1 |
|---|---|---|
| Область приложения (PRCT) | `0x04000-0x9CFFF` | `0x04000-0x92FFF` (слот приложения 0x8DFBC) |
| Хранилище прошивки | `0x9D000-0xBAFFF` (тег владельца 0xAF000) | у Felucca: `0x97000-0xDFFFF`; настройки `0xFC000-0xFEFFF` |
| Staging обновления | `0xBB000-0xBFFFF` | `0xE0000-0xE4FFF` (запись на 0xE4F00) |
| Автосохранение и прочее | внутри окна хранилища | `0xE5000-0xE7FFF` |
| Никогда не пишется | `0x0-0x3FFF`, `0xC0000-0xC1FFF`, `0xF4000-0xFDFFF`, `0xFF000-` | `0x0-0x3FFF`, `0xE8000-0xFBFFF` (резервная VM-копия штатного OTA, BTIF, USR), `0xFF000-` |
| Идентичность пакета | `SMK-37 Pro_9XY` (Elite, MKE-P37: их имена) | `FM-1_9XY` |
| Запись обновления | `ota-SMK-37 Pro_016` | `ota-FM-1_015` |
| Пакет | 36-блочная штатная раскладка, таблица областей SMK | 20 блоков, таблица областей FM-1 |

- Возьмите половину FM-1 из `fm1_flash_map.h` и таблицу FM-1 из `fm1pkg_make.py` как есть. Объект, который сборка
  SMK держит на SMK-адресе, получает адрес FM-1 внутри окон FM-1, никогда не исключение из защиты.
- Тег владельца SMK не имеет пары на FM-1 (`st_owner_check` там пуст): две прошивки на одном FM-1 встречают
  записи друг друга в тех же объектах. Дайте каждой записи магическое число, размер, версию и контрольную сумму,
  и считайте всё остальное пустым.
- Соберите загрузчик обновления FM-1 без флага SMK: загрузчик FM-1 остаётся побайтово идентичным вышестоящему.
- Установщики: пакет FM-1 никогда на SMK и пакет SMK никогда на FM-1, на каждом пути (install и resume;
  жёсткое правило 9 в AGENTS.md). Добавьте USB-имя прошивки в фильтры портов установщиков.

## 3. Во что превращаются дополнения SMK

| SMK-37 | FM-1 | Примечания |
|---|---|---|
| Пэды как переключатели (режимы, киты, звуки) | ALGORITHM или PRESETS (один щелчок — выбор), список на экране | Состояние переключателя на экране; светодиод клавиши или кнопки для активного, где это помогает |
| Пэды как памяти (нажатие — загрузка, удержание — сохранение) | PRESETS указывает на память (поворот загружает её), SAVE удерживаемый 1 с сохраняет в неё | Показывайте номер памяти и пуста ли она |
| Удерживаемые пэды как эффекты (RECORD, ECHO, stutter) или переключаемые (PLAY) | Удерживаемые или нажимаемые кнопки (REC, PLAY, ARP, ...) | Их светодиоды горят при удержании или включении |
| Фейдеры (абсолютные, мягкий перехват) | Вторая или третья страница KNOB 1..4, переключаемая SEL (и SELECT), HOME — возврат на первую | Название страницы на экране; относительным ручкам перехват не нужен |
| Колёса | Отброшены или ручка на странице | MIDI pitch bend и CC1 продолжают приходить по USB |
| Крайние клавиши, velocity | Отброшены; фиксированное velocity | |
| K1 виртуальный MASTER | Потенциометр MASTER | Читайте его до старта аудио (без скачка при включении) |
| < и > (страницы, памяти) | SELECT / PRESETS | |
| Комбинации кнопок SMK (< + > удерживаемые) | Две свободные кнопки FM-1 (например, ENV + LFO) | Оставьте OCT- + OCT+ удерживаемые 5 с для UBOOT на обеих |
| Цвета RGB-пэдов | Светодиоды кнопок и экран | |

Сохраняйте экран одинаковым на обеих платах (240 x 240 на обеих): меняются только ячейки или метки, называющие
орган управления (SMK «K5» становится FM-1 «1» для KNOB 1 и так далее).

## 4. Шаги

1. **Переключатель платы.** Один флаг (`BOARD_SMK37` 0 / 1) и, когда сборка FM-1 репозитория должна оставаться
   вышестоящей прошивкой, отдельная цель сборки для FM-1-версии новой прошивки (Vox37: `BOARD=fm1vox`, раскладка
   и идентичность FM-1, своя единица компиляции; `BOARD=fm1` по-прежнему собирает Felucca побайтово).
2. **HAL.** Подключайте `fm1_input.h` и `fm1_adc.h` вместо `smk_input.h`; выбросьте части только для SMK
   (светодиоды пэдов, trim-кривые, тактовый генератор ЖК SMK). Просмотрите общие исходники greпом на `smk_`,
   `SMK_`, `fm1_in.pad`, `fm1_in.fader`, `fm1_in.wheel`, `fm1_in.keys`, `key_vel` и `padled` и дайте каждому путь FM-1.
3. **Файл панели.** Положите код ввода и светодиодов каждой платы в свой файл (Vox37: `vo_panel_smk.c`,
   `vo_panel_fm1.c`) с одним маленьким интерфейсом: читать органы управления, вызывать общие действия (задать
   значение, загрузить, сохранить, открыть страницу), зажигать светодиоды, называть ячейки экрана. Общие действия
   и экран остаются в одном файле.
4. **Хранилище.** Адреса FM-1 для каждого объекта (раздел 2), распознаваемая запись, защита без изменений.
5. **Идентичность.** `FM-1_900` (релиз `FM-1_9XY`), USB-имена — собственные для прошивки.
6. **Тесты.** Хостовый тест панели FM-1 против заглушённого `fm1_in` (кнопки, шаги энкодеров, ноты, записи
   светодиодов); рендеринг экранов FM-1. Прогоните и тесты SMK: разделение не должно менять поведение сборки SMK.
7. **Сборка обеих.** Пакеты SMK, затем пакет FM-1, затем (последним) вышестоящая сборка FM-1 для набора тестов
   (обе пишут одни и те же промежуточные файлы в `build/`, см. [07-develop-for-both.md](07-develop-for-both.md)).

## 5. Подводные камни

| Подводный камень | Исправление |
|---|---|
| Код читает поля `fm1_in`, отсутствующие у ввода FM-1 (`keys`, `key_vel`, `pad_st`, `fader`, `wheel`). | Читатели по платам в файле панели; общий код спрашивает панель. |
| Идентификаторы кнопок SMK используются как числа (10 GLOBE, 14 FX) в общем коде. | Называйте их в файле панели; идентификаторы FM-1 другие (FX 2, GLO 7). |
| Код светодиодов пишет `fm1_led[id]` как массив 19 байт вкл/выкл (SMK). | На FM-1 `fm1_led[]` хранит битмапы колонок: используйте `fm1_led_key(id, on)`. |
| Хранимое значение виртуального потенциометра (SMK K1) восстанавливается поверх настоящего MASTER FM-1. | Храните его только на SMK; FM-1 читает свой потенциометр. |
| Уведомление тега владельца хранилища SMK («NEW STORE») или другие символы только для SMK в главном цикле. | Защищайте их; у FM-1 нет тега владельца. |
| Время во фреймах (625/с на SMK, 909/с на FM-1). | Миллисекунды. |
| Тактовый генератор ЖК SMK 20 МГц перенесён как есть. | Сохраняйте 12 МГц FM-1, пока не измерено на устройстве. |
| Функция USB-host (микрофон) сочтена работающей на FM-1. | Тот же чип и порт, но не проверено: помечайте экспериментальной, держите device-режим (путь обновления) по умолчанию, когда есть компьютер. SMK не подаёт VBUS устройству; порт FM-1 не измерен. |
| Установщиккий путь, пропускающий проверку модели, предлагает пакет SMK для FM-1 (или наоборот). | Проверка модели на каждом пути, с тестами. |
| Сборка FM-1 репозитория изменилась (новый флаг, правка общего файла без защиты). | Отдельная цель для FM-1-сборки новой прошивки; сравнивайте хэши вышестоящего FM-1. |

## 6. Разобранный пример: Vox37 на FM-1

`BOARD=fm1vox sh build.sh` собирает `vox37-fm1.fwsc` (идентичность `FM-1_900`, раскладка и загрузчик обновления
FM-1). Экран — от SMK; панель — `firmware/src/vo_panel_fm1.c`; хостовый тест — `tests/vo_fm1.c`.

| SMK-37 | FM-1 |
|---|---|
| K1 MASTER | Потенциометр MASTER |
| Верхние пэды 1..4: режимы | ALGORITHM |
| Нижние пэды 1..8: памяти (нажатие / удержание 1 с) | PRESETS (поворот: загрузка), SAVE удерживаемый 1 с: сохранение |
| K2..K8, фейдеры 1..4 | KNOB 1..4 на трёх страницах: MAIN (VOICE BLEND TONE COLOR), SOUND (WAVE TIMBRE SHAPE), MORE (HISS VOL RELEASE ENSEMBLE SPACE); SEL / SELECT страницу, HOME — первую |
| Пэд 7 RECORD (удержание), пэд 8 PLAY (нажатие; удержание + < >: воспроизведение), пэд 6 ECHO (удержание) | REC удержание, PLAY (удержание + SELECT: воспроизведение), ARP удержание |
| FX HISS, OCTAVE- / + | FX, OCT- / OCT+ |
| GLOBE MIC SETUP (K5..K8, пэд 5 RESET) | GLO (KNOB 1..4, EDIT RESET) |
| < + > удерживаемые 3 с: USB host | ENV + LFO удерживаемые 3 с |
| Колёса | отброшены (MIDI bend и CC1 работают) |
| 37 клавиш с velocity | 27 клавиш, velocity 100; их светодиоды зажигают зажатые ноты |

USB-микрофон на FM-1 не проверен.

## Контрольный список

- [ ] Один флаг; собственная сборка FM-1 репозитория без изменений (хэши), FM-1-сборка новой прошивки — отдельная цель
- [ ] `fm1_input.h` / `fm1_adc.h` на FM-1; никакого SMK HAL, светодиодов пэдов, trim-кривых или тактового генератора ЖК SMK в ней
- [ ] Каждый орган только для SMK нашёл дом на FM-1 (раздел 3) или отброшен намеренно; ни один орган не повторяет другой
- [ ] MASTER из потенциометра; velocity клавиш фиксировано; время в миллисекундах
- [ ] Каждый хранимый объект на адресе FM-1 внутри окон FM-1; защита без изменений; записи распознаваемы
- [ ] Идентичность `FM-1_9XY`, загрузчик обновления FM-1 побайтово идентичен, 20-блочный пакет FM-1
- [ ] Установщики отвергают пакет FM-1 на SMK и наоборот, на каждом пути
- [ ] Хостовый тест панели FM-1; экраны FM-1 отрендерены; тесты SMK по-прежнему проходят
- [ ] Функции, которые FM-1 ещё не проверил (устройство USB-host), помечены экспериментальными в README
