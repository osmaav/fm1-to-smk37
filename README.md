# OpenHands Runtime — русская локализация

**Версия релиза: 1.0.0** | **Дата: 22 октября 2026 г.**

Этот репозиторий содержит среду выполнения (runtime) проекта [OpenHands](https://github.com/All-Hands-AI/OpenHands), полностью локализованную на русский язык: все комментарии в исходном коде и docstrings переведены на русский, а каждый файл снабжён версионным заголовком локализации.

## Описание

Пакет `openhands` реализует сервер исполнения действий агента (action execution server):

- **`openhands/action_execution_server.py`** — HTTP-сервер (FastAPI), принимающий действия агента и возвращающий наблюдения;
- **`openhands/events/`** — схема событий: действия (actions) и наблюдения (observations), их сериализация и хранилище событий;
- **`openhands/runtime/`** — среда выполнения: браузерная обвязка (Playwright), плагины (Jupyter, VS Code, agent skills), прокси MCP;
- **`openhands/core/`** — исключения, конфигурация и журналирование;
- **`openhands/utils/`** — утилиты: разбор bash-команд, редактирование файлов, мониторинг памяти, git-операции и др.;
- **`openhands/storage/`, `openhands/linter/`** — хранилище файлов и линтер.

## Русская локализация

Перевод выполнен инструментом `translate_comments.py` — словарно-фразовым переводчиком комментариев и docstrings Python.

### Особенности реализации

1. **Все комментарии на русском языке.** Строковые (`# ...`) и inline-комментарии (`код  # ...`) переведены; технические директивы (`# noqa`, `# type:`, `# pylint: disable=` и т.п.) сохранены без изменений.
2. **Версионный заголовок в каждом файле.** В начало каждого обработанного файла вставлена строка:
   ```python
   # Версия локализации: 1.0.0 | Файл переведён на русский язык автоматически.
   ```
3. **Соблюдение принципа версионности (идемпотентность).** Повторный запуск переводчика не переписывает уже переведённые (русские) комментарии и docstrings — изменения накапливаются только для нового/непереведённого кода. Это позволяет выпускать последовательные релизы локализации (1.0.0 → 1.1.0 → …) без регрессий.
4. **Безопасность синтаксиса.** Переводчик анализирует код через `ast`, защищает строковые литералы от ложных срабатываний символа `#` и проверяет результат компиляцией каждого изменённого файла.

### Структура переводчика

| Компонент | Назначение |
|---|---|
| `WORD_MAP` | Частотный словарь «английское слово → русский перевод» (~2000 статей) |
| `PHRASE_FIXES` | Устойчивые фразы целиком (например, `current working directory → текущий рабочий каталог`) |
| `RULES` | Служебные маркеры: `TODO`, `FIXME`, `NOTE`, секции docstrings (`Args:`, `Returns:`…) |
| `POST_RULES` | Второй проход — замена кальк на естественные русские обороты |
| `find_comment_start()` | Поиск начала комментария вне строковых литералов |
| `add_file_header()` | Вставка версионного заголовка локализации |

## Установка и запуск

Требования: Python ≥ 3.12.

```bash
pip install -r requirements.txt
```

Запуск сервера исполнения действий:

```bash
python -m openhands.action_execution_server --port 30001 --id runtime-1
```

Передача действий агенту выполняется HTTP-запросами на эндпоинты `/action`, `/observe`, `/set_config`, `/alive` (см. исходный код с русскими комментариями).

## Повторная локализация (для новых версий)

```bash
python translate_comments.py openhands --version 1.1.0
```

Инструмент обработает только англоязычные комментарии, сохранив ранее переведённые, и проставит актуальный номер версии локализации.

## Лицензия

Проект распространяется под лицензией MIT (как и上游-проект OpenHands). Локализация не изменяет функциональность кода — переведены только комментарии и docstrings.
